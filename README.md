# Cuti-BlockLeave# Cuti-BlockLeave

Sistem pengajuan dan pengelolaan **Block Leave Pekerja Definitif BO Kayu Agung** berbasis web.

Aplikasi ini digunakan untuk membantu proses pengajuan cuti tahunan dengan memperhatikan periode Block Leave, hari kerja, hari libur, dan ketentuan tanggal yang berlaku.

## ✨ Fitur

- 📅 Pengajuan cuti berdasarkan kalender
- 🚫 Validasi tanggal Block Leave
- 🗓️ Validasi hari kerja Senin–Jumat
- 🎉 Pengecualian tanggal merah / hari libur
- ⚠️ Validasi tanggal yang tidak dapat dipilih
- 👤 Pengelolaan data pekerja
- 📊 Rekap pengajuan cuti
- 📄 Export data pengajuan
- 📥 Import / konversi data dari file
- 💻 Responsive untuk desktop dan perangkat mobile

## 🏢 Informasi

**Unit Kerja:** BO Kayu Agung  
**Sistem:** Block Leave  
**Periode:** Tahun 2027  
**Hari Kerja:** Senin–Jumat

## 🛠️ Teknologi

Project ini dibangun menggunakan teknologi web:

- HTML5
- CSS3
- JavaScript
- Excel / XLSX untuk pengolahan data
- Vercel untuk deployment
